# Changelog

## 0.7.0

- VPN внутри EasyZapret с пользовательскими ключами и подписками, импортом VLESS/Reality/XHTTP, VMess, Trojan, Shadowsocks, Hysteria2, TUIC и AnyTLS
- Режимы VPN для всех приложений, только выбранных приложений, обход VPN выбранными приложениями и локальный HTTP/SOCKS5-прокси
- Правила по доменам, IP-подсетям и процессам, настройка DNS, MTU, IPv6, стека TUN и автоподключения
- Переподключение при изменении настроек с попыткой восстановления предыдущего профиля при ошибке
- Исключения VPN-адаптера и серверов в фильтре zapret, восстановление маршрутов при отключении, контроль совместного запуска с WARP
- Шифрование VPN-ключей и ссылок подписок через Windows DPAPI для текущей учетной записи

Черновая сборка для проверки на Windows. Требуется проверка реального подключения с пользовательским ключом. Зашифрованные ссылки Happ и внешние плагины Shadowsocks пока не поддерживаются.

## 0.6.3

- Атомарная запись состояния автопилота: смена сети и удачные стратегии больше не теряются при сбое записи
- Системные уведомления автопилота, когда окно свёрнуто в трей (смена стратегии, деградация, новая сеть)
- Шаримый конфиг: экспорт/импорт JSON со всеми настройками приложения, списками и параметрами вкладки «Сервис»
- На странице WARP показывается предупреждение, если запущены ExitLag, GearUP и похожие программы
- Релизные заметки берутся из `CHANGELOG.md`; добавлен скрипт `npm run bump`
- Обновлены зависимости: rustls, sysinfo, tauri plugins, vitest, tailwindcss, GitHub Actions

## 0.6.2

- Автопилот замечает смену сети и сначала проверяет стратегию, которая уже работала в ней
- Обновления IPSet и hosts показываются в общей плашке обновлений
- Обновление hosts сохраняет пользовательские записи и создаёт резервную копию
- Обновление IPSet сохраняет выбранный режим фильтра
- Если права на `C:\EasyZapret` сбились (например, открыли папку в Проводнике и нажали «Продолжить»), приложение больше не блокирует запуск и не заставляет сносить данные

## 0.6.1

- Усилены обновления компонентов и проверка каталога данных
- Исправлен clippy для релизной сборки
